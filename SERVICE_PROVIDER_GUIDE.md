# Service Provider Professional Profile Guide

## Overview

This guide helps service providers create a **professional, verified, and trustworthy profile** on the DENUEL Rental platform.

---

## 🎯 Profile Completeness

A complete professional profile includes:

### 1. Basic Information ✅
- Business name
- Contact details (phone, email)
- Physical address and service areas
- Business description and bio
- Logo/profile photo
- Cover photo (optional)

### 2. Professional Details 📋
- Service category
- Specific services offered
- Pricing (hourly rate, price range, minimum charge)
- Years in business
- Working hours
- Languages spoken
- Skills and specializations

### 3. Verification Documents 🔒
Required documents for verification:
- **National ID (NRC)** - Identity verification
- **Business License** - Legal business operation
- **Professional Certifications** - Skills validation
- **Insurance Certificate** - Coverage protection
- **Tax Clearance (TPIN)** - Tax compliance

Optional but recommended:
- Reference letters
- Background check
- Additional qualifications

### 4. Work Experience 💼
Add your professional work history:
- Job title/position
- Company/employer name
- Duration (start and end dates)
- Location
- Responsibilities and achievements
- Projects completed
- Skills used

**Tips:**
- Add current position (mark as "Current")
- Include self-employment periods
- Quantify achievements (e.g., "Completed 50+ projects")
- List relevant skills for each role

### 5. Professional Certifications 🎓
Add all your credentials:
- Certification name
- Issuing organization
- Certificate number
- Issue and expiry dates
- Verification URL (if available)
- Certificate document
- Skills validated by this certification

**Examples:**
- Plumbing License from Zambia Board
- Electrical Technician Certificate
- HVAC Certification
- First Aid Certificate
- Safety Training Certificates

### 6. Portfolio Showcase 🎨
Display your best work:
- **Project title** - Clear, descriptive name
- **Description** - What you did
- **Before/after photos** - Show transformations
- **Additional images** - Multiple angles
- **Project details**:
  - Duration (how long it took)
  - Cost (budget range)
  - Location
  - Client testimonial (with permission)
- **Skills/tags** - Techniques used
- **Mark featured** - Highlight best work

**Portfolio Best Practices:**
- Use high-quality photos
- Show diverse projects
- Include before/after for renovations
- Add client testimonials
- Update regularly
- Feature your best work (3-5 projects)

## 🔒 Security & Verification

### Verification Levels

**Level 0: Unverified** (Basic account)
- Can create profile
- Limited visibility
- No verification badge

**Level 1: Basic Verified** ✓
- ID verification (NRC)
- Email and phone verified
- Basic badge displayed

**Level 2: Standard Verified** ✓✓
- All Level 1 requirements
- Professional certifications verified
- Business license verified
- Standard badge displayed

**Level 3: Premium Verified** ✓✓✓ (Recommended)
- All Level 2 requirements
- Insurance certificate verified
- Tax clearance verified
- Background check completed
- Premium badge displayed
- Higher search ranking
- More customer trust

### Document Requirements

#### Identity Documents
- **NRC (National Registration Card)** - REQUIRED
  - Clear, readable photo
  - All 4 corners visible
  - Not expired
  - Name matches profile

#### Business Documents
- **Business License** - REQUIRED for business entities
  - Valid/current license
  - Business name matches profile
  - Issued by PACRA or local authority

- **TPIN Certificate** - REQUIRED for tax compliance
  - Tax Payer Identification Number
  - Valid certificate from ZRA

#### Professional Credentials
- **Certifications/Licenses** - HIGHLY RECOMMENDED
  - Trade-specific licenses
  - Professional qualifications
  - Training certificates
  - Membership certificates

#### Insurance Documents
- **Professional Indemnity Insurance** - RECOMMENDED
  - Coverage details
  - Expiry date
  - Insurance provider name

- **Public Liability Insurance** - RECOMMENDED
  - Protects clients
  - Shows professionalism

### Document Upload Guidelines

**File Requirements:**
- Format: PDF, JPG, PNG
- Size: Maximum 5MB per file
- Quality: Clear, readable text
- Valid: Not expired

**Security Measures:**
- Documents encrypted at rest
- Only visible to admins for verification
- Watermarked on display (if shown publicly)
- Secure storage with access logs

**Verification Process:**
1. Upload document
2. Admin reviews within 2-3 business days
3. Verification status updated
4. Email notification sent
5. Badge displayed on profile

**Document Expiry:**
- System tracks expiry dates
- Automatic warnings 30 days before expiry
- Reminders sent via email/SMS
- Profile visibility reduced if expired

## 📊 Professional Portfolio Tips

### Creating an Impressive Portfolio

#### Photo Guidelines
1. **Quality Matters**
   - Use good lighting
   - High resolution (minimum 1200x800px)
   - Clear, focused images
   - Professional appearance

2. **Show Progress**
   - Before photos (initial state)
   - During photos (work in progress)
   - After photos (final result)
   - Close-ups of details

3. **Variety**
   - Different project types
   - Various locations
   - Different scales (small to large)
   - Diverse techniques

#### Project Descriptions
- **Be specific**: "Installed new electrical system with circuit breakers and LED lighting" vs "Did electrical work"
- **Include details**: Materials used, challenges overcome, special techniques
- **Highlight skills**: What made this project special?
- **Client results**: How did it help the client?

#### Client Testimonials
- Request written testimonials
- Get permission to use client name
- Include photos if permitted
- Short, specific feedback works best
